# DevSetup

Avant de commencer à développer des applications, il est important de disposer d'un environnement de travail correctement configuré. Ce dépôt rassemble les principaux outils que j'utilise ainsi que quelques notes qui me seront utiles tout au long de mon apprentissage.

## Configuration Git

Pour configurer Git avec son identité :

```bash
git config --global user.name "votre nom"
git config --global user.email "votre-adresse@email.com"
```

Puis vérifier la configuration :

```bash
git config --global --list
```
