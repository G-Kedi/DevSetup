# Configuration et bonnes pratiques

Ce document rassemble quelques éléments de configuration et les bonnes pratiques que j'applique dans mes projets.

## Configuration Git

Configurer mon identité :

```bash
git config --global user.name "Gédéon KEDI KITOKO"
git config --global user.email "votre-adresse@email.com"
```

Vérifier la configuration :

```bash
git config --global --list
```

## Extensions Visual Studio Code utilisées

- Prettier
- Live Server
- GitLens
- Thunder Client

## Bonnes pratiques

- Faire des commits réguliers avec des messages explicites.
- Organiser les fichiers du projet de manière claire.
- Tester les modifications avant chaque commit.
- Lire la documentation officielle des outils utilisés lorsque nécessaire.
