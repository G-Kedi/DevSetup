# Commandes utiles

Cette page regroupe les commandes que j'utilise le plus souvent pendant le développement.

## Navigation dans le terminal

```bash
pwd
ls
cd dossier
mkdir nouveau-dossier
```

## Commandes Git

```bash
git init
git status
git add .
git commit -m "Mon message"
git push origin main
git pull origin main
```

## Commandes Node.js et npm

```bash
node --version
npm --version
npm install
npm run dev
```

## À retenir

Ces commandes constituent une base que j'enrichirai progressivement au cours de ma formation.
