# Installation de l'environnement

Ce document résume les différentes étapes suivies pour préparer mon environnement de développement.

## Logiciels installés

- Visual Studio Code
- Git
- Node.js (version LTS)

## Vérification des installations

Après l'installation, j'ai vérifié que chaque outil était correctement installé en exécutant les commandes suivantes :

```bash
git --version
node --version
npm --version
code --version
```

## Pourquoi ces outils ?

- **Visual Studio Code** : éditeur de code léger et performant.
- **Git** : outil de gestion de versions permettant de suivre les modifications du projet.
- **Node.js** : environnement d'exécution JavaScript utilisé pour le développement web moderne.
- **npm** : gestionnaire de paquets fourni avec Node.js.

## Remarque

Ce document pourra être complété au fur et à mesure de mon apprentissage et de l'installation de nouveaux outils.
